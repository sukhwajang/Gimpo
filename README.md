# 김포–서울 지하철 혼잡 시뮬레이터

서울–김포 실제 지도 위에 지하철 노선을 3D로 그리고, **역 주변 아파트 인구**로 아침 출근길 혼잡을 시뮬레이션하는 웹앱입니다.

- **기존 노선 그대로**: 수도권 19개 노선, 역 470곳을 실제 좌표로 표시합니다 (편집 불가, 운행 횟수·정원만 조정 가능).
- **계획안 선택**: 5호선 김포·검단 연장, GTX-D(김포~부천 / 강남·하남 요구안), 대장홍대선, 인천2호선 고양 연장, 골드라인 증편 가정을 켜고 끌 수 있습니다.
- **아직 계획에 없는 노선 그리기**: 지도를 클릭해 역을 찍으면 새 노선이 생깁니다. 기존 역 근처를 누르면 환승역이 됩니다.
- **혼잡도 3D 표시**: 역간 구간마다 진행 방향 오른쪽에 혼잡도만큼 솟은 "벽"이 생기고, 색은 혼잡도(초록→노랑→빨강→보라)입니다. 열차가 노선을 따라 움직입니다.
- **시간대별**: 06:00~10:00를 30분 단위로 보고, 재생 버튼으로 출근 시간 흐름을 볼 수 있습니다.
- **현재 대비 비교**: 골드라인 최고 혼잡도, 김포·검단 철도 통근 시간, 철도 이용률, 대표 경로(구래→여의도 등) 소요시간이 현재(2026)와 비교됩니다.
- **저장·공유**: 브라우저에 자동 저장되고, `공유 링크`로 시나리오를 URL로 보낼 수 있습니다. JSON/CSV 가져오기·내보내기도 됩니다.

## 실행

```bash
npm install
npm run dev        # http://localhost:5173
npm test           # 시뮬레이션·네트워크 테스트
npm run build      # dist/ 에 정적 사이트 생성
```

서버가 필요 없는 정적 웹앱입니다. 시뮬레이션은 브라우저의 Web Worker에서 1초 안팎으로 돌아갑니다.

### 파일 하나로 보기 (설치 없이)

```bash
npm run build:single   # dist-single/index.html 하나에 모든 코드·데이터가 들어감
```

만들어진 `index.html` 을 크롬·엣지에서 더블클릭하면 바로 열립니다. 배경지도는 인터넷이 연결돼 있어야 보이고, 연결이 안 되면 행정경계만 있는 오프라인 지도로 바뀝니다.

### GitHub Pages 배포

`.github/workflows/deploy.yml` 이 `main` 브랜치에 푸시될 때 테스트 → 빌드 → Pages 배포를 합니다.
저장소 **Settings → Pages → Source** 를 **GitHub Actions** 로 한 번 바꿔 주면 `https://<계정>.github.io/<저장소>/` 로 열립니다.

## API 키 — 무엇을 받아야 하나

**키 없이도 앱은 전부 동작합니다.** 기본 배경지도(CARTO, OpenFreeMap)는 키가 필요 없고, 아파트 세대수는 추정치가 내장돼 있습니다. 아래 키는 정확도와 지도 품질을 높이고 싶을 때 받으면 됩니다.

| 우선순위 | 어디서 | 무엇을 신청 | 앱에서 쓰는 곳 |
|---|---|---|---|
| 1 | [브이월드](https://www.vworld.kr) → 오픈API → 인증키 발급 | **오픈API 인증키** (WMTS 배경지도 + 지오코더) | 한국어 배경지도·야간지도·항공사진. 아파트 주소 → 좌표 변환 |
| 2 | [공공데이터포털](https://www.data.go.kr) → 활용신청 | **국토교통부_공동주택 단지 목록제공 서비스**<br>**국토교통부_공동주택 기본 정보제공 서비스** | 단지별 실제 세대수 (추정치 대체) |
| 3 (선택) | [서울 열린데이터광장](https://data.seoul.go.kr) | **서울시 지하철 호선별 역별 시간대별 승하차 인원 정보** | 모형 보정·검증용 (현재 앱에는 미연결) |

### 브이월드 키 쓰는 법
1. 브이월드 회원가입 → 오픈API → 인증키 발급.
2. **서비스 URL** 에 앱 주소를 등록합니다. 예: `http://localhost:5173`, `https://<계정>.github.io`. 등록하지 않은 주소에서는 지도가 뜨지 않습니다.
3. 앱 **설정 탭 → 브이월드 API 키** 에 붙여 넣고 배경 지도에서 `브이월드 …` 를 고릅니다. 키는 그 브라우저에만 저장됩니다.

### 실제 아파트 세대수 넣는 법
공공데이터포털 두 서비스를 활용신청하면 하나의 **일반 인증키(Decoding)** 로 둘 다 쓸 수 있습니다.

```bash
DATA_GO_KR_KEY=공공데이터포털_인증키 VWORLD_KEY=브이월드_인증키 \
  node scripts/fetch-apartments.mjs 41570 28260 28245 11500 11470 > apartments.csv
# 시군구 코드: 김포 41570, 인천 서구 28260, 계양 28245, 강서 11500, 양천 11470
```

만들어진 `apartments.csv` 를 앱의 **단지·인구 → CSV 불러오기** 로 넣으면, 같은 지역의 추정치를 0으로 바꿔 중복 계산을 막을지 묻습니다.
CSV 형식은 `name,region,lat,lon,households` 입니다 (직접 만든 엑셀을 CSV로 저장해도 됩니다).

> `fetch-apartments.mjs` 는 키가 없는 환경에서 만들어 실제 API로는 아직 실행해 보지 못했습니다. 공공데이터포털 API 주소가 바뀌었으면 `APT_LIST_URL`, `APT_INFO_URL` 환경변수로 덮어쓰면 됩니다.

## 시뮬레이션 방식

1. **출근 인원** = 세대수 × 가구원(2.4) × 출근 비율 × 기타 수요 배율
   - 김포·검단·계양·강서·양천은 생활권별 아파트 단지군(추정)으로, 나머지 지역은 시군구 가구 수를 역별로 나눈 배경 수요로 넣습니다.
2. **목적지** = 업무지구 39곳(광화문, 여의도, 마곡, 강남, G밸리 등)의 일자리 규모 × 거리 감쇠 + 거주지 근처 통근(철도 미이용)
3. **수단 선택** = 철도(걷기·마을버스 접근 + 대기 + 차내 + 환승 + 혼잡 불편) vs 버스·승용차 로짓
4. **경로 배정** = 혼잡을 반영한 최단 경로를 6번 반복 배정(MSA)해서 한 노선에 몰리지 않게 합니다
5. **혼잡도** = 구간 시간당 승객 ÷ (시간당 열차 수 × 열차 정원). 30분 수요를 시간당으로 환산해 표시합니다
6. **보정** = 현재 상태에서 골드라인 고촌→김포공항이 최고 약 200%(실제: 최근 평균 180%대, 과거 최고 285%)가 나오도록 계수를 맞췄습니다. 모형 밖 수요(경기 남부·동부 유입 등)는 노선별 `bg` 값으로 넣었습니다 (`scripts/lines.config.mjs`).

계수는 앱 **설정 탭**에서 바꿀 수 있습니다. 결과는 **상대 비교와 토론용**이며 정책 판단용 수요 예측이 아닙니다.

## 데이터 출처와 한계

- 역 좌표: 공공데이터 기반 전국 도시철도 역 정보 (2026-06 기준, `data/raw/subway_stations_20260630.csv`). 원본 오류 3곳(5호선 마곡, 4호선 이촌, 경의중앙선 양원)은 `scripts/lines.config.mjs` 에서 보정했습니다.
- 행정경계: 통계청 2013 시군구 경계 ([southkorea-maps](https://github.com/southkorea/southkorea-maps)).
- 아파트 세대수, 운행 횟수, 열차 정원: 공개 자료를 바탕으로 한 **추정치**입니다.
- 계획 노선: 2026년 11월까지의 보도를 정리했습니다. **역 위치는 대부분 가칭·개략 위치**이고(지도에서 속이 빈 원), 기본계획에서 바뀔 수 있습니다. 각 계획 카드에 출처 링크가 있습니다.
- 지도에 없는 노선(GTX-A, 경강선 등)과 연구 범위 밖 지역의 수요는 단순화했습니다.

## 구조

```
scripts/
  lines.config.mjs       기존 노선 정의 (역 순서, 색, 운행 파라미터, 배경 수요)
  districts.config.mjs   시군구 가구 수 (배경 수요)
  build-network.mjs      → src/data/generated/*.json 생성 (npm run build:network)
  fetch-apartments.mjs   공공데이터포털·브이월드로 실제 단지 CSV 만들기
src/
  data/                  계획 노선, 아파트 단지군, 업무지구
  sim/                   네트워크 구성, 수요·수단선택·배정 시뮬레이션, Web Worker
  map/                   MapLibre + deck.gl 3D 레이어, 열차 애니메이션, 배경지도
  ui/                    노선·단지·설정 탭, 결과 패널
  state/                 상태 관리, 저장·공유, 시뮬레이션 실행
```
